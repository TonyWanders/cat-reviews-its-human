A program that writes one funny single-line one-star review, written by a house cat about its human, to `/output/entry.txt`, for the make.fun competition [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

Run it with Python 3:

```sh
python3 main.py
```

It writes the review below to `/output/entry.txt` (or to the path given as the first argument, or `$OUTPUT_PATH`). No network, no clock, no randomness. The review is 138 characters, inside the 1 to 200 gate, a single line with no em dash.

## The review

```
One star. Breakfast arrived four minutes late and half full, so I knocked his coffee off the table and blamed the dog, who does not exist.
```
